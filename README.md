# mano

一个记录每日时间日志的终端程序。按事项写下开始时间、结束时间和内容，持续时间自动算出。

所有数据存在一个 Markdown 文件里，纯文本，随时可以用别的编辑器打开。

## 安装

### 脚本安装

macOS / Linux：

```sh
curl -fsSL https://raw.githubusercontent.com/ParadiseWitch/mano/main/install.sh | bash
```

Windows PowerShell：

```powershell
irm https://raw.githubusercontent.com/ParadiseWitch/mano/main/install.ps1 | iex
```

脚本会检测平台、下载对应二进制并校验 sha256，默认装最新 Release（`MANO_VERSION=v0.1.0` 可指定版本）。

### 下载二进制

从 [Releases](https://github.com/ParadiseWitch/mano/releases) 下载对应平台的文件：

| 平台 | 文件 |
| --- | --- |
| macOS (Apple Silicon) | `mano-darwin-arm64` |
| macOS (Intel) | `mano-darwin-amd64` |
| Linux x64 | `mano-linux-amd64` |
| Linux arm64 | `mano-linux-arm64` |
| Windows x64 | `mano-windows-amd64.exe` |

macOS：

```sh
chmod +x mano-darwin-arm64
sudo mv mano-darwin-arm64 /usr/local/bin/mano
```

Windows PowerShell：

```powershell
Move-Item mano-windows-amd64.exe $HOME\bin\mano.exe
```

### 从源码构建

需要 Go 1.24 或更新版本。

```sh
git clone https://github.com/ParadiseWitch/mano.git && cd mano
make build                       # 产物在 dist/mano
cp dist/mano /usr/local/bin/     # 或任何在 PATH 里的目录
```

交叉编译 Windows 版本（在 macOS/Linux 上也能构建）：

```sh
make build-windows   # 产物在 dist/mano-windows-amd64.exe
```

### 更新与卸载

装好之后：

```sh
mano version      # 打印版本号
mano update       # 检查最新 Release，下载校验后替换自身
mano uninstall    # 删除 mano 本体（会先确认；日志与配置保留）
```

`update` 只替换二进制本身，不碰数据；Windows 上被占用的旧文件改名后由后台进程清理。手动从源码构建的二进制版本号是 `devel`，`update` 会把它升到最新 Release。

## 运行

```sh
mano                       # 打开今天的日志
mano -date 2026-08-01      # 打开指定日期，也可写 20260801
mano -file ~/notes/time.md # 换一个数据文件
```

默认数据文件是 `~/.mano/mano.md`，目录和文件都会在第一次保存时自动创建。

第一次运行还会在 `~/.mano/config.toml` 落一份配色文件，里面写着当前主题（默认 `catppuccin`，另有 `onedark`），改主题或改单个颜色都在这份文件里，见「配色」。

按 `q` 退出。所有修改即时写入文件，退出前不需要保存。

## 数据文件

一个文件装下所有日期，日期升序排列：

```markdown
# 20260801

1. 日志事项1内容

- START: 09:00
- END: 10:21

2. 日志事项2内容

- START: 10:30
- END: 11:21

# 20260802

1. 只写了内容，没有时间
```

`- START:` 和 `- END:` 都是可选的，缺哪个就不写哪一行。

**注意**：mano 独占这个文件。每次保存都会用当前内存里的日志**重写整个文件**，凡是 mano 认不出的行（别的标题、列表、备注、空行以外的内容）都会被丢弃。想在这个文件里记别的东西，请另建文件，或用 `-file` 指定不同的路径。

写入是原子的：先写临时文件再改名替换，中途崩溃不会留下半个文件。文件权限 `0600`，目录权限 `0700`。

## 配色

界面配色写在 `~/.mano/config.toml`，第一次运行时自动创建。文件里生效的只有一行——主题；17 个颜色都以注释的形式列在下面，各带一句说明和当前主题的取值，去掉行首的 `#` 再改掉，就盖过主题里的那一个颜色。

文件开头长这样（后面还有十五个颜色）：

```toml
# mano 界面配色。改完保存，重启 mano 生效。

# 主题，可选 catppuccin、onedark。
theme = "catppuccin"

# 下面是 catppuccin 的取值：去掉行首的 # 改掉，就盖过主题里的这一个颜色。
[colors]
# 程序整体底色，列表行就坐在它上面
# background = "#1e1e2e"
# 选中行的底色
# row = "#313244"
```

### 主题

`theme` 一次换掉整套颜色，要写在 `[colors]` 之前（写在段里会报错，并告诉你挪上去）。内置两套：

| 主题 | 出处 |
| --- | --- |
| `catppuccin` | Catppuccin Mocha：色卡的强调色当文字用，选中行抬到 surface0，光标块走粉，底栏沉到 mantle。**默认** |
| `onedark` | Atom One Dark：语法色当文字用，选中行抬到行高亮灰，光标块走类名的黄 |

写了没有的主题名，程序照样起得来：底栏报 `第 N 行没有这个主题：xxx（可选 catppuccin、onedark）`，整套配色退回默认主题，文件里认得的行照常生效。主题名不分大小写。

### 单个颜色

- 颜色一律写作 `#rrggbb`，值要用引号包起来，没加引号的行会被报成读不懂。
- `[colors]` 段里的行盖过主题；没写的颜色跟着主题走，所以换主题只需要改上面那一个词。
- 文件已经存在时 mano 不会覆盖它，也不会写回任何内容；想拿到最新的模板（比如又多了一个颜色），删掉文件重新运行。
- 改完要重启 mano。
- 读不懂的行只影响它自己：其余行照常生效，每一处问题都会被逐条写进底栏那一行提示（说明是第几行、哪里不对，条目之间用「；」隔开），下一次按键就换回正常的按键提示。找不到主目录时同样直接用默认配色，程序不会因此起不来。

| --- | --- | --- | --- |
| `background` | `#1e1e2e` | `#282c34` | 程序整体底色，列表行就坐在它上面 |
| `row` | `#313244` | `#3e4451` | 选中行的底色 |

## 快捷键

### 日志页 · 内容列

每一行由八个「停靠点」组成，光标默认停在**内容列**，列表层面的命令都在这里：

| 键 | 作用 |
| --- | --- |
| `j` / `k` | 换项：下移、上移一项（上下方向键同效，`PgUp` / `PgDn` 翻页） |
| `J` / `K` | 挪本项：把当前项下移、上移一格，光标跟着走 |
| `Tab` / `Shift+Tab` | 换停靠点，两端环绕 |
| `gg` / `Home` | 跳到第一项 |
| `G` / `End` | 跳到最后一项 |
| 数字键 | 跳到对应序号；300ms 内连按可拼成多位数（先按 `1` 再按 `2` 跳到第 12 项） |
| `i` / `a` | 编辑当前项内容，光标落在开头 / 结尾（`Enter` 等同于 `a`） |
| `o` | 在下一行插入新项，开始时间填当前时间，并直接进入编辑；上面那条只有开始、没有结束的项，结束时间自动填成同一个当前时间 |
| `dd` | 删除当前项，之后选中下一项 |
| `y` | 复制当前项（含内容与起止时间） |
| `p` | 把复制的项粘贴为最后一项并选中 |
| `0` | 跳到序号停靠点 |
| `c` | 打开日期选择页 |
| `?` | 打开帮助页 |
| `q` | 退出 |

`gg` 和 `dd` 需要在 800ms 内连按两个键；按下第一个键后底栏会显示等待状态，超时或按了别的键就取消。

首位的 `0` 不再参与拼数字（没有第 0 项，它被让给了序号列），但先按 `1` 再按 `0` 仍然跳到第 10 项。

### 日志页 · 一行的八个停靠点

选中那一行的光标停在其中一处：序号、开始 小时、开始 分钟、结束 小时、结束 分钟、耗时 小时、耗时 分钟、内容。`Tab` 与 `Shift+Tab` 在这些停靠点之间走，两端环绕；`j` / `k` 和 `J` / `K` 在哪个停靠点都是同一件事，只有上下键看停在哪儿。底栏会跟着换，写明当下这几个键的含义——停在内容列那一行是 `内容 j/k 换项 J/K 挪本项 Tab 换列 i 编辑 o 新建 dd 删 y/p 复制 c 日期 q 退出`。

| 键 | 作用 |
| --- | --- |
| `Tab` / `Shift+Tab` | 在停靠点之间移动，两端环绕：从内容列按一次 `Tab` 到序号，连按七次走完一圈回到内容 |
| `0` | 跳到序号停靠点（时间列除外，那里的 `0` 是个数字） |
| `Enter` / `Esc` | 从其他停靠点回到内容列（内容列上的 `Enter` 是开始编辑） |
| `j` / `k` | 换项：移动光标，行的位置不变；时间列上一样，按它不会顺手改掉数值 |
| `J` / `K` | 挪本项：把当前项下移、上移一格，光标跟着走，整行的读数一起搬 |
| 序号列上下键 | 与内容列一样换项：序号就是位置，改不了它 |
| 时间列上下键 | 调整数值：小时每次 ±1，`23` 时再加 1 变成 `00` 时；分钟每次 ±5，在 `00`–`59` 之间绕回，不进位也不借位到小时 |
| 时间列数字键 | 一位一位滚动填入，没有任何等待计时：先改十位、再改个位，两次按满一个数值，第三次起重填下一个 |
| 时间列 `s` | 把当前时间填进开始或结束时间，只有这两列认这个键 |
| 耗时列上下键、数字键 | 同样加减小时和分钟，改动写回结束时间（耗时是算出来的，没法只改它）；没有开始时间时不改，底栏说明原因 |

数字这一条值得说细些：按下的一位当场就落进那一半，屏幕上看到的一直是完整数值，既没有 `1_` 那样的半位，也不会过一秒才生效。时钟装不下的那一次按下（时超过 `23`、分超过 `59`）不写数值、不写文件、连该轮到哪一位也不动，只在底栏报出本列的最大值。从 `00` 起依次按 `1` `2` `0` `5`，小时读作 `10`、`12`、`02`、`05`；已经是 `19` 时按 `3`、按 `2` 都会被拒（`39` 与 `29` 都过了 `23`），接下来的 `1` 仍落在十位（还是 `19`），`8` 才落到个位，于是 `18`。

开始或结束时间本来是空的，在时间列上加减会从 `00:00` 起算，想直接填现在按 `s`。换停靠点、离开又走回来，都会把填入的顺序拨回十位，已经写下的数值保留。

`i` / `a`、`o`、`gg`、`G`、`dd`、`y` / `p`、`c`、`J` / `K`、`?`、`q` 这些行命令在任何停靠点上都能按；只有数字例外——落在时间列上就是时间的一部分。

日志页的列只能由 `Tab` 换：`h` / `l` 与左右键在这里不换停靠点，也不改数值，什么都不做。日期选择页的 `h` / `l` 仍是翻页。

结束时间早于开始时间时，视为跨到了第二天，持续时间按 +24 小时计算，耗时列改走 `crossed` 配色。

### 日志页 · 编辑模式

| 键 | 作用 |
| --- | --- |
| 左右键 | 移动光标 |
| `Backspace` | 删除光标前一个字符 |
| `Enter` / `Esc` | 提交并回到内容列 |

编辑期间改动只在缓冲区里，`Enter` 或 `Esc` 退出时才写入文件。

### 日期选择页

| 键 | 作用 |
| --- | --- |
| `j` / `k` | 下移、上移一个日期（上下方向键同效） |
| `h` / `l` | 上一页、下一页（左右方向键同效，`PgUp` / `PgDn` 亦是） |
| `/` | 开始搜索，边输入边过滤 |
| `Enter` | 打开选中的日期 |
| `c` / `Esc` | 返回日志页 |
| `?` | 打开帮助页 |
| `q` | 退出 |

列表里只有文件中已有的日期和今天，按日期倒序，每行显示条目数。

### 搜索

| 输入 | 结果 |
| --- | --- |
| `2026-08` | 按日期过滤，紧凑写法 `202608` 同样有效 |
| 关键词 | 按日志内容过滤，找出写过该词的日子 |
| `20260801` | 输入一个没有记录的完整日期，底栏提示后按 `Enter` 直接新建当天 |
| `Esc` | 清空搜索并取消 |

### 帮助页

`?` 打开，`q` / `Esc` / `?` 返回日志页。`j` / `k` 或上下键滚动，`PgUp` / `PgDn` 翻页。

### 通用

`Ctrl+C` 在任意页面强制退出。

## 行为约定

- 条目**不自动排序**，始终保持插入顺序，序号就是列表里的位置；要挪动就在任何停靠点上按 `J` / `K`。
- 持续时间只在开始和结束时间都存在时才有值，否则该列显示占位 `--h--m`；任一方改动都会重算。没填的时间与算不出的耗时不花本列的强调色：它们用 `dim` 色写在所在行的底色上，真有读数的那几列才亮起来。耗时那一列自己不存数，在它上面加减或填数字都写回结束时间；没有开始时间时无从推算，按键什么也不改，底栏写明 `耗时由起止时间算出，先填开始时间`。
- 时间列的数字是一位一位落定的：按下即生效、即写盘，先十位后个位；装不进时钟的那一位整个丢弃，不夹取也不排队等待，程序里没有任何针对输入的计时器。
- 日志行的每一列只用自己的强调色写字，不铺底色：序号、开始、结束、耗时、内容五列靠颜色区分，列之间不留空白，时间数值前后各留一格空格。整行唯一的底色是选中行那一层（`row`），其余行坐在 `background` 上。
- 光标停在哪个停靠点，那一处就换成 `field` 打底、`ink` 写字——时间列与耗时列只铺被按中的那半个数值，序号列是整格；同一列的其余部分保持本列的强调色。选中行的内容文字换成 `selected`，正在编辑时换成 `editing`；内容没写的显示 `（无内容）`，用 `dim` 色。当前项另在行首以 `warn` 色的 `>` 标出。
- 标题、列表、底栏之间是一条 `divider` 色的细线（`─`）。
- 底栏的提示随停靠点而变，写明当下这几个键是干什么的；配置文件读不懂的行也报在这里。
- 空的一天显示 `今日暂无记录，按 o 新建`。

## 开发

```sh
make test    # go test ./...
make vet     # go vet ./...
make fmt     # gofmt -w .
make dist    # 同时构建本机版和 Windows 版
make clean   # 删掉 dist/
```

测试覆盖数据层（解析、序列化、往返一致、原子写）、配色文件（两套内置主题各自完整、模板与读回一致、单个颜色盖过主题、没有的主题名退回默认并报出行号、坏行不拖累好行）、按键状态机（`gg` / `dd` 前缀、数字跳转）、自更新与卸载（版本号解析、sha256 校验、坏包拒绝替换、原地替换、确认与取消）和日志页的八个停靠点（绕着行走一圈、加减与绕回、滚动填入数字与拒绝越界、挪动条目、每次改动落盘、底栏提示的措辞与宽度）。终端里的实际观感仍需手工看。

代码结构：

```
main.go                  命令行入口，子命令分发，读主题与配色
internal/config/         配色：两套内置主题、文件模板、容错读取
internal/store/          数据层：模型、Markdown 解析与序列化、原子写
internal/keys/           多键序列状态机，不依赖 bubbletea，可单测
internal/selfupdate/     update / uninstall：查版本、下载校验、原地替换自身
internal/ui/             三个页面的渲染与按键处理
```

## CI

`.github/workflows/ci.yml`：推到 `main` 或开 PR 时，在 ubuntu / macos / windows 上跑 `gofmt`、`go vet`、`go test` 和构建。

`.github/workflows/release.yml`：推 `v*` 形式的 tag 时，跑完测试、交叉编译 macOS / Linux（arm64 与 x64）与 Windows x64 共五个产物，连同 `checksums.txt` 一起用 `gh` 建一个 Release 传上去，供安装脚本和手动下载使用。

```sh
git tag v0.1.0
git push origin v0.1.0
```
